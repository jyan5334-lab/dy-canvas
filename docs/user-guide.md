# DY画布使用手册

这是一个无后端的本地白板版本，适合做讲解、演示和逻辑关系梳理。

## 运行

### Windows 桌面版

- 运行 `DYCanvas-Setup-1.0.1-x64.exe` 安装，适用于 Windows 10 / 11 的 64 位系统。安装时可选择目录，并创建桌面和开始菜单快捷方式。
- 安装后直接打开“DY画布”，无需浏览器、Node.js、网络连接或本地服务。
- 1.0.1 使用选定的朱红色 Logo，应用内标识、窗口、安装器和快捷方式统一更新。覆盖升级沿用原有应用身份和画布数据目录。
- 桌面数据保存在 `%APPDATA%\WirelessCanvas`，与程序安装目录分开。关闭窗口前会等待当前编辑保存；升级安装沿用此目录，卸载默认保留数据。
- 浏览器版和桌面版的数据独立。将浏览器画布导出为 JSON，再在桌面版导入，即可迁移节点、编组、连线和已保存的附件。
- 桌面版导出或下载原附件时会出现 Windows 保存对话框，可自行选择保存位置。

### 浏览器版

直接双击 `index.html` 即可打开。也可以使用项目内置的零依赖 Node 静态服务器：

```powershell
node serve.cjs
```

然后访问 `http://localhost:4173`。

### 从源码构建桌面版

在项目根目录安装 Node.js 依赖后执行：

```powershell
npm ci
npm run dist:win
```

在 Windows 中构建。构建工具会校验并准备 Electron 运行时，安装包输出到此项目的 `release/` 目录。运行 `npm start` 可开发调试桌面窗口，`npm run pack:win` 只生成解包后的桌面程序。首次安装依赖和构建工具需要网络，打包后的应用可离线运行。

源码仓库只包含程序源码、Logo、示例素材与依赖锁定文件，不包含 `node_modules/`、安装包、个人画布数据或登录凭据。`npm ci` 会按 `package-lock.json` 还原依赖。

## 功能

- 界面采用中性灰／石墨色工作台，提供白天、夜晚两套主题；图标文件随应用打包，离线打开也可显示。
- 右侧使用色点选择节点颜色，白天模式下节点正文、标题栏和边框呈现对应的低饱和浅色，夜晚模式使用深色底与彩色标记；使用“新连接样式”分段按钮选择后续连线的实线／虚线。缩放和适应画布位于画布右下角。
- 手机端通过顶部文件菜单使用新建、保存、导入和导出，内容与属性通过两侧面板按钮打开。

- 双击画布空白处，在菜单中选择文本、图片、视频、文档或其他内容。
- 按住节点右侧输出点，立即出现曲线箭头；保持鼠标左键按下并拖向目标节点左侧输入点，松开后建立连接。
- 在空白区域松开会取消本次连接。新增节点使用双击空白处的菜单。
- 拖动时箭头随鼠标移动，使用与正式连线相同的曲线和实线／虚线样式；移到有效输入点会高亮吸附。松在空白处、按 Esc 或切出窗口可取消，不会留下临时连线。
- 使用左键拖动画布空白区域可以移动整张画布。
- 拖动卡片标题移动节点。
- 滚轮缩放，按住空白处拖动画布，支持适应画布。
- 图片可以从左侧选择、拖入画布，或直接粘贴图片。
- 支持白天和夜晚模式，主题状态会保存在本地。
- 文本节点可以在右侧“节点说明”输入，也可以直接在画布节点正文中输入，两个位置会同步。
- 双击节点标题可原地改名，输入内容同步显示在右侧。按 Enter 或点击别处保存，Esc 取消；单击拖动标题栏仍用于移动节点。
- 文本节点会根据换行后的实际内容自动增高，不使用正文滚动条；节点高度也会随画布保存。
- 每条连接独立保留创建时的实线或虚线样式；切换“新连接样式”只影响之后创建的连接。混合样式会随画布保存、导出和恢复；旧版画布的已有连线按原有统一样式恢复。
- 单击连线可选中，双击可编辑连接文字，例如“原因”“结果”“补充”。右侧“当前连接样式”只修改选中的这一条线；Delete / Backspace 或右侧删除按钮可单独删除连接，支持撤销。
- 画布自动保存到浏览器本地存储，也支持 JSON 导入和导出。

## 导出

- 点击顶部“导出”，选择 PNG 图片或 JSON 画布文件；手机端先打开顶部文件菜单。
- PNG 包含整张画布的节点、连线、章节和编组，按内容范围自动裁切，保留当前主题和浅色节点背景，不包含工具栏、侧栏、连接点及选中高亮。
- 图片保留节点文字和本地图片，已加载的视频显示为当前静态画面，文档显示为文档节点；PNG 用于展示，JSON 用于再次导入编辑。
- 图片默认以两倍分辨率输出，较大画布会自动降低比例以完整导出。导出组件已随项目打包，无需联网。

## 节点编组

- 按住 `Shift`，在画布上用鼠标左键拖动选区，选区覆盖的节点会高亮；松开鼠标后保留选择。支持任意方向框选和缩放后的画布。
- 按 `Esc` 可取消正在进行的框选；不按 Shift 时，左键拖动空白处仍然移动画布。
- 点击左侧“将选中节点编组”，会创建一个类似 ComfyUI 的编组框。
- 编组标题显示在外框上方，可在右侧修改名称；拖动标题会带着组内节点整体移动，右下角手柄可以调整编组范围。
- 选中编组后，可以在右侧修改编组名称、备注和尺寸；删除编组框不会删除节点。
- 点击编组标题或右下角标记后，外框、标题和角标会同步高亮；选中其他节点或编组时，高亮随之切换。选中的编组可按 Delete / Backspace 或使用右侧删除按钮移除，组内节点仍保留。
- 编组只用于整理画布，不会自动变成讲解章节，也不会改变节点之间的连接关系。
- 点击编组标题右侧的箭头或右侧“折叠编组”，可收起或展开。收起后显示节点数量，内部连线隐藏，对外连线接到编组边缘；移动收起的编组仍会带动成员，展开后保留原来的范围。
- 节点四角和四边中点使用透明缩放热区，悬停时只显示对应方向的双向箭头光标，不显示边条或方块。
- 手动拖动的宽度和高度会保存；空白或少量文字不会使节点回缩。文字按节点宽度自动换行，增加内容时高度可继续扩展；删除文字最多缩回手动设置的高度。

## 章节与讲解

- 选中一个节点后，点击左侧“从当前内容新建章节”，为它创建章节框；没有选中节点时，使用当前视野中的节点创建。
- 在左侧选择章节，在右侧修改章节名称、讲解备注、宽高和顺序。备注保存在画布内，讲解时不显示在观众画面中。
- 拖动章节标题会连同章节内的节点一起移动；拖动章节框右下角可以调整范围。删除章节框会保留节点。
- 点击顶部“讲解”，隐藏编辑面板并聚焦当前章节，其他章节内容淡出。
- 用左右方向键、PageUp / PageDown 或底部按钮切换章节，按 Esc 退出并恢复原来的编辑视角。
- 在章节属性中勾选“逐步显示节点”，用上下箭头调整节点顺序。进入讲解后先显示第一项，右方向键、空格或“下一步”逐项展开；左方向键可回退。连接只会在两端节点均显示后出现。退出后恢复完整编辑画面，原编组的折叠状态保留。

## 搜索与文档

- 点击画布工具栏的搜索图标或按 Ctrl+F，搜索节点标题、正文、文件名、编组和章节名称。点击结果或用上下键和 Enter 跳转，目标短暂高亮；编组内隐藏的节点会自动展开。
- 文档节点保存实际文件内容，随画布本地保存和 JSON 导出；可以下载原文件，预览 PDF 或 TXT / Markdown / CSV / JSON 纯文本。Word、Excel、PowerPoint 等文件请下载后用本地应用打开。
- 旧版本只记录文件名的文档节点需重新附加原文件，无法从文件名恢复之前未保存的内容。

## 本地画布库

- 点击画布工具栏的文件夹图标打开画布库，查看缩略图、修改当前画布名称、切换画布或归档其他画布；归档后可恢复。
- “新建画布”和“导入画布”会保留原画布，导入作为另一张画布保存。每张画布的撤销历史独立，切换时重新开始。
- 原有单画布草稿会自动迁入本地数据库。画布、图片、视频和文档均保存在此浏览器的 IndexedDB 中，不上传服务器；更换浏览器、地址或清除站点数据不会自动迁移，请使用 JSON 转移和备份。
- “历史版本”最多保留最近 10 个快照。编辑时约每分钟保留一个，手动保存会为尚未记录的最新内容创建版本；恢复前会保存当前内容，恢复操作也可以撤销。历史版本需要浏览器支持本地数据库。

## 撤销与保存

- 顶部箭头按钮或 Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做。支持文字修改、移动、连线、编组折叠、章节操作和版本恢复。
- 编辑历史最多保留 80 个状态，仅在当前页面会话内有效；刷新后仍保留已保存的画布，但撤销历史重新开始。
- 使用同一浏览器、同一地址打开以恢复本地草稿。重要画布建议导出 JSON 备份。
- 图片、视频和文档保存在浏览器本地数据库中，容量由浏览器和设备剩余空间决定。保存失败会明确提示，并阻止新建或切换覆盖尚未保存的内容。

此版本只做本地讲解和演示，不包含图片生视频、文字生图片等生成能力，也不会上传媒体文件。
