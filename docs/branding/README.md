# DYcanvas 标识

名称统一写作 **DYcanvas**：大写 DY，小写 canvas。

- `dycanvas-icon-master.png`：高清透明背景源图。
- `../../media/dy-canvas-symbol.png`：应用内使用的 512px 图标。
- `../../desktop/icon.png`：桌面窗口图标。
- `../../desktop/icon.ico`：Windows 图标，包含 16 / 24 / 32 / 48 / 64 / 128 / 256px。

图形将 D 的轮廓与 Y 形分叉连接结合，使用朱红色标识与石墨色底。桌面安装时同时提供带版本号的独立 ICO 资源，用于刷新旧快捷方式图标。

更新品牌时保留应用 ID `com.local.wirelesscanvas`、包名 `wireless-canvas`、可执行文件 `WirelessCanvas.exe` 和数据目录 `%APPDATA%\WirelessCanvas`，保证旧版检测与原画布数据兼容。
